🔒 数据不出本机

串口链路在浏览器内直连飞控,服务器只承担页面分发与你主动上传的备份/日志。AI 分析用你自己的 Key,服务端不保存任何密钥。

⚡ 免安装即开即用

没有安装包、没有驱动、没有环境依赖。Chrome / Edge 打开 HTTPS 网页就能连飞控 —— 图书馆的电脑也能调参。

🔗 仿真与调参同域联动

两个系统部署在同一站点:先在仿真台把桨/电机/电池方案算清楚,再进调参台把 PID 落到实机,思路不断档。

🏠 一键自部署

Docker Compose 一条命令部署到自己的服务器(支持 nginx 前置反代 + Let's Encrypt 证书),数据完全自己持有。
