# 04 · 界面操作与结果解读

本文说明**画布、曲线、数据表、快捷键**分别在看什么，以及**命中/脱靶是如何判定**的 ——
把界面元素与背后的物理量一一对应起来。

## 2. 战场画布元素

| 元素 | 颜色/样式 | 含义 |
| :--- | :--- | :--- |
| 网格 + 刻度 | 灰色，每 2 km 一条主线 | 坐标刻度，单位 km，原点在左下 |
| 图例(左上) | 目标航线/比例导引(PN)/纯跟踪(PP) | 当前显示哪些轨迹；**结束后换成结果横幅** |
| 目标航线 | 青色，粗淡线 + 虚线 | 目标飞机已飞过的路径 |
| 比例导引弹道 | 橙色，发光线条 | PN 导弹轨迹 |
| 纯跟踪弹道 | 品红色，发光线条 | PP 导弹轨迹 |
| 初始位置 × | 十字标记 | 导弹发射点 / 目标起始点(可拖拽定位) |
| 视线 (LOS) | 与导弹同色的虚线 | 导弹→目标的连线，长度即 R |
| R 标注 | 视线中点旁 `R=x.xx km` | 实时相对距离(太近时不显示，避免遮挡) |
| 命中半径圆 | 青色点线圆 | 目标周围 R_hit 杀伤区，视觉化"多近算命中" |
| 目标图标 | 青色飞机，机头 = 航向 | 标签显示 `目标 TGT 250 m/s`，机动时附 `ω=+6.0°/s` |
| 导弹图标 | 橙/品红导弹 + 尾焰 | 尾焰亮 = 正在推进；箭头 = 速度矢量方向 |
| 导弹标签 | 图标旁两行 | 第 1 行 `名称 + 速度`；第 2 行 `n=…g  λ̇=…°/s` |
| 中段弹道 | 暗色**虚线** | 仅分段制导开启且跨过截获点后出现(截获前的弹道) |
| 视场锥 FOV | 弹体前方淡色三角 + 点线边 | 未截获时显示，尖端标 `FOV 90°`；目标须落在锥内才可能截获 |
| 截获圆 R_acq | 与导弹同色的暗色虚线圆 | 未截获时显示(进入该圆才"够得着") |
| 截获点标记 | 十字 × + `截获 t=5.8s R=3.99km` | 截获之后；同时导弹标签追加 `[中段]`/`[末段]` |
| 底部状态行 | 左下 | `t = x.xx s  状态(就绪/运行中/仿真结束)` |
| 提示行 | 底部(仅就绪时) | 拖拽与快捷键提示 |
| 结果横幅 | 顶部(仅结束后) | `比例导引: 命中 (脱靶量 0.2 m) | 纯跟踪: 脱靶 67.8 m (飞越目标)` |

**鼠标操作**：光标移到导弹/目标图标上变成"手形"，按住左键拖动即可改变初始位置；
空白处光标为十字。拖拽会实时同步右侧坐标框，并自动重置仿真。

## 3. 曲线区(左下)

### 3.1 上图：相对距离 R(t) [m]

- 纵轴 0 → 初始距离最大值，横轴为仿真时间 t [s]。
- **健康形态**：近似直线单调下降到 0 —— 说明弹道平直、接近速度稳定。
- **末端翘起/抬高**：说明导弹已经"错过"，距离先减小后增大(飞越)。
- **两线对比**：橙线(PN)通常下降更陡更直；品红线(PP)因弹道弯曲，下降略缓。

### 3.2 下图：导弹法向过载 a(t) [m/s²]

- 纵轴自动按 **±Gmax** 取满量程，图中画有两条**水平参考虚线 = ±Gmax**。
- **读法**：
  - 曲线**顶到虚线** = 过载饱和(硬件打满)，此时导引律"有心无力"，脱靶风险高；
  - 前段尖峰 = 初始离轴角修正；
  - 中段平缓 ≈ 0 = 已进入平行接近段(比例导引的典型特征)；
  - **末端持续上冲并贴线** = 纯跟踪的末端发散特征。
- 两幅图**共用同一时间轴**，可上下对照"什么时候饱和 → 距离曲线何时变形"。
- 启用分段制导后，两幅图各有一条**竖虚线**（与导弹同色，标注 `XX截获`），
  标出导引头截获时刻 —— 可对照"截获前后过载曲线形态的变化"（中段平缓 → 末段开始修正）。

## 4. 实时数据表(右侧)

| 行 | 符号 | 含义与读法 |
| :--- | :---: | :--- |
| 时间 t (s) | t | 该导弹已飞行时间 |
| 相对距离 R (m) | R | 导弹↔目标直线距离 |
| 接近速度 Vc (m/s) | Vc | **正值 = 正在接近**，负值 = 已经拉远(飞越) |
| 视线角 λ (°) | λ | 视线相对 +x 轴的角度 |
| 视线角速率 λ̇ (°/s) | λ̇ | **PN 的核心观测量**；趋近 0 = 已抓住碰撞航线 |
| 过载 a (m/s²) | a | 实际法向过载(已限幅、已滞后) |
| 过载 n (g) | n | 同上，换算成 g 倍数，便于和 Gmax 比较 |
| 弹速 Vm (m/s) | Vm | 当前弹速(本程序恒定) |
| 制导阶段 | — | `中段`(导引头未截获) / `末段`(已截获)；未启用分段制导时恒为 `末段` |
| 截获时刻 (s) | t_acq | 已截获显示时刻，否则 `-` |
| 最小距离 (m) | — | **脱靶量**：整条弹道上的最小距离 |
| 结果 | — | 飞行中 / 命中 / 脱靶(飞越目标) / 超时 |

- 列 1 = 比例导引，列 2 = 纯跟踪；单弹模式下另一列自动隐藏。
- 数值用**导弹颜色**着色，未激活时变灰。
- 只有"最小距离"和"结果"在结束后才有最终意义，其余为瞬时值。

## 5. 结果判定规则

### 5.1 脱靶量(最小距离)

脱靶量不是"采样点上的最小 R"，而是**目标到每一段弹道折线的点到线段距离**的最小值
(`guidance.py → closest_on_segment`)，因此即使最小点落在两个积分步之间也能精确得到。

### 5.2 命中

- 判据：**脱靶量 ≤ 命中判定半径 R_hit**(默认 25 m)。
- 一旦满足只**打上命中标记，仍继续积分**到"飞越目标"才结束 ——
  这样"最小距离"才是**整条弹道的真实最小值**，不会因为提前停止而低估/高估。

### 5.3 结束条件(任一满足)

| 条件 | 说明 |
| :--- | :--- |
| 飞越目标 | 曾经接近(Vc > 0)，随后**连续远离 ≥ 0.3 s**，且当前距离不大于 `max(2000 m, 1.5×已得最小距离)` |
| 超时 | 单枚导弹飞行时间 ≥ 60 s |
| — | 双弹对比时，两枚都出结果才判整场结束 |

### 5.4 结果字符串

- 命中：`命中 (脱靶量 12.3 m)`
- 未命中：`脱靶 67.8 m (飞越目标)` 或 `脱靶 350.0 m (超时)`
- 启用分段制导且**始终未截获**时附注：`… · 导引头未截获`

显示位置：**画布顶部横幅 + 底部状态栏汇总**。

## 7. 常见现象 FAQ

**Q1：为什么一改参数、一拖位置，仿真就自动回到 t=0？**
为了保证可比性 —— 每次实验都从相同初始条件出发。改动后需重新点「▶ 开始」。

**Q2：倍速调到 8× 会不会改变结果？**
不会。倍速只是"每帧多推进几个 0.02 s 的步长"，任意倍速下的数值结果完全一致。

**Q3：为什么默认场景里纯跟踪的脱靶量(几十米)远大于比例导引(不到 1 米)？**
纯跟踪始终指向目标**当前位置**，末端需要的转弯率随 R→0 发散，受 Gmax 限制来不及拐；
比例导引则在前段就转到碰撞航线上，末端几乎不需要过载。详见 [01](01_比例导引法PN.md) 与 [02](02_纯跟踪法PP.md)。

**Q4：a(t) 曲线一直贴着 ±Gmax 虚线怎么办？**
说明已经过载饱和 —— 要么提高 Gmax，要么降低难度(目标速度/机动、离轴角)，
要么换更合适的 N / K。

**Q5：两枚导弹一开始重叠在一起，看不清？**
因为它们共用同一起点与初始航向。想看"不同起点"的公平性，可切换单弹模式分别观察，
或看弹道颜色差异(橙/品红)。

**Q6：λ̇ 一开始很大是不是错了？**
正常。发射瞬间前置角不为 0，视线转率天然较大；比例导引会把它迅速压到 0，
这正是它在工作的证据。若 λ̇ 长期不降，说明过载不足或 N 太小。

**Q7：目标飞出战场边界了还在继续跑？**
战场边长只是显示范围。可以调大「战场边长」或把目标位置/航向改回来。

**Q8：帮助文档改了没生效？**
在帮助窗口点 **「🔄 刷新」**；若新增了 `.md` 文件，刷新后会自动出现在左侧列表。
