# 01 · 比例导引法 (Proportional Navigation, PN)

> **一句话概括**：让导弹速度矢量的转动角速度，与视线(LOS)的转动角速度成正比 —— **ψ̇ = N · λ̇**。
> 只要 N > 2，λ̇ 就会被迅速压到 0，视线不再转动，双方沿"平行接近线"相撞。

比例导引是空空导弹、地空导弹**最经典、应用最广**的导引律，本程序中由橙色导弹体现。

---

## 1. 几何关系与符号

```
                y
                |        目标 T (xt, yt) 速度 Vt
                |         ●────────→ Vt
                |        /
                |   R  /  λ (视线角)
                |     /
                |    ●────────→ Vm  ψ (航向)
                |  导弹 M (xm, ym)
                +---------------------------→ x
```

- **视线 (Line of Sight, LOS)**：连接导弹质心 M 与目标质心 T 的线段，长度记为 **R**。
- **视线角 λ**：`λ = atan2(yt − ym, xt − xm)`，即视线相对 +x 轴的角度。
- **视线转率 λ̇**：λ 随时间的变化率，是比例导引唯一的"测量输入"。
- **航向 ψ**：导弹速度矢量方向。**前置角**定义为 `φ = ψ − λ`，表示导弹速度相对视线偏了多少。
- **法向过载 a**：垂直于速度方向的加速度，控制航向转动：`ψ̇ = a / Vm`。

## 2. 相对运动方程

把目标相对导弹的运动投影到"视线方向"和"垂直视线方向"：

- 沿视线方向：`Ṙ = Vt·cos(qt) − Vm·cos(qm)`，其中 `qt = θt − λ`、`qm = ψ − λ`。
  定义 **接近速度 Vc = −Ṙ**（Vc > 0 表示正在接近）。
- 垂直视线方向：`R·λ̇ = Vt·sin(qt) − Vm·sin(qm)`。

第一式控制"什么时候到"，第二式控制"轨迹往哪拐"。导引律要做的事，就是**不断调整 qm，让 λ̇ 变号并趋于 0**。

## 3. 比例导引律

对航向应用：

```
ψ̇ = N · λ̇                    (N > 0，常用 3 ~ 5)
```

因为 `ψ̇ = a / Vm`，所以过载指令为：

```
a_cmd = N · Vm · λ̇            ← 经典形式
```

工程上更常用**接近速度**代替弹速（称为"真比例导引 TPN / 带重力修正的形式"）：

```
a_cmd = N · Vc · λ̇            ← 工程形式(本程序默认)
```

本程序把两种形式做成了一个复选框 **「PN 系数用接近速度 Vc」**：
勾选 → `a_cmd = N · Vc · λ̇`；不勾选 → `a_cmd = N · Vm · λ̇`。
当 Vc ≤ 0(正在远离)时自动退化为 Vm，避免系数变负导致指令反向。

### 3.1 为什么 λ̇ → 0 就能命中？

把 `ψ̇ = N·λ̇` 代入垂直视线方向的运动方程，并对时间求导（假设 Vm、Vt 大小不变），可得：

```
R·λ̈ + Ṙ·λ̇ + (N−2)·Vc·λ̇  ≈  0      (略去目标机动项)
```

记 `Λ = λ̇`，则近似有：

```
Λ̇ = −[(Ṙ/R) + (N−2)·Vc/R] · Λ
```

由于接近过程中 `Ṙ < 0`，只要 **N > 2**，方括号内就是**正**的，`Λ` 指数衰减到 0：

```
Λ(t) = Λ(0) · exp( −∫[ (N−2)·Vc − |Ṙ| ]/R dt )
```

λ̇ → 0 意味着**视线方向不再变化**，即"导弹与目标的相对方位保持不变" —— 这就是经典的 **平行接近原理 (Parallel Approach)**：两条平行视线最终必然相交于一点，即碰撞点。

- **N = 2**：临界，衰减很慢，脱靶量对初始误差敏感。
- **N > 2**：λ̇ 指数收敛，N 越大收敛越快。
- **N < 2**：λ̇ 不收敛，通常脱靶很大(除非初始就在碰撞航线上)。

### 3.2 弹道的两个阶段

1. **初始段**：若发射时前置角不为 0，λ̇ 较大，导弹产生较大过载把速度矢量转到"碰撞航线"上。
2. **平行接近段**：λ̇ ≈ 0，过载接近 0，弹道平直地"等着"目标撞上来 —— 这就是比例导引过载需求**比纯跟踪小得多**的原因。

> **碰撞三角形 / 前置角**：理想碰撞条件下 `Vm·sin(φ) = Vt·sin(qt)`，即
> `φ = asin( Vt·sin(qt) / Vm )`。目标速度越快、越接近横向交会，需要的前置角越大。
> 本程序默认 Vt/Vm = 250/600 ≈ 0.42，横向交会时前置角约 25°。

## 4. 本程序中的实现

代码位置：`guidance.py → Missile.guidance_command()`

```python
if self.kind == "pn":
    v_ref = vc if (p.use_vc and vc > 0.0) else float(self.speed)
    return p.nav_ratio * v_ref * los_dot
```

观测由 `Missile.sense()` 完成：

```python
los     = math.atan2(dy, dx)
los_dot = (dx * rvy - dy * rvx) / max(r2, 1.0)     # λ̇ = (r × v_rel) / R²
vc      = -(dx * rvx + dy * rvy) / r                # Vc = -(r · v_rel)/R
```

之后依次经过 **过载限幅 → 执行机构一阶滞后 → 运动学积分**，详见 [仿真参数详解](03_仿真参数详解.md)。

## 5. 导航比 N 怎么选

| N | 特点 | 典型场景 |
| :---: | :--- | :--- |
| 1 ~ 2 | 收敛慢，末端过载需求发散，脱靶大 | 基本不用 |
| 2 ~ 3 | 初始过载小，但末端对目标机动残留误差大 | 远程、目标机动弱 |
| **3 ~ 5** | **收敛快、全程过载需求较均匀(常用 3.5~4.5)** | **通用，本程序默认 4** |
| 5 ~ 6 | 更快压住目标机动，但初始过载尖峰大 | 高机动目标 |
| > 6 | 对测量噪声(λ̇ 噪声)放大，抖动、执行机构打摆 | 一般避免 |

**规律**：N 越大 → 前段越"急"、过载尖峰越高；N 越小 → 后段越"急"、末端容易过载饱和而脱靶。
最佳点通常是：**整条弹道过载曲线尽量平、且不长时间顶在 ±Gmax 上**。

## 6. 优缺点

**优点**

- 脱靶量小、过载需求小(尤其末段)，对目标机动的适应性好。
- 只需测量视线角速率 λ̇ 和接近速度 Vc —— 导弹上用速率陀螺 + 多普勒雷达即可实现。
- 理论成熟，工程实现简单可靠。

**缺点 / 失效模式**

- **过载饱和**：N 太大或初始离轴角太大时，指令超过 ±Gmax，实际跟踪不了 λ̇，脱靶量急剧增大。
- **低速端失效**：接近速度 Vc → 0(尾追同速、或横向交会瞬时)时 `a_cmd = N·Vc·λ̇` 变得很小，改用 Vm 形式或切到复合制导。
- **λ̇ 测量噪声**：末端 R 很小时 λ̇ 数值发散，真实系统需要滤波(本程序为理想测量)。
- **需要"看得见"目标**：PN 的输入 λ̇ 只有导引头截获目标后才存在 ——
  在那之前必须靠惯导/数据链把导弹送进截获窗口，见 [05 · 中段制导与拦截点计算](05_中段制导与拦截点计算.md)。

## 7. 在程序里观察什么

- **下方 a(t) 曲线**：比例导引的过载通常"前段有尖峰 → 中段平缓 → 末端平稳"，且很少顶满 ±Gmax 虚线。
- **数据表 λ̇ 一行**：开局数值大，随后**快速趋近 0** —— 这就是"抓住了碰撞航线"的直接证据。
- **数据表 Vc 一行**：应为正且逐渐接近 Vm 量级；若变负说明已经飞过目标。
- **R(t) 曲线**：近似线性下降到 0，说明弹道平直、接近匀速逼近。

## 8. 动手实验

1. **N 敏感性**：把 N 从 2 → 4 → 6 各跑一次，比较三条 R(t) 曲线与最大过载。
2. **Vc 开关**：勾选/取消「PN 系数用接近速度 Vc」，看脱靶量与过载峰值差异(尾追场景差异最明显)。
3. **过载限制**：把 Gmax 从 9 g 调到 3 g，观察过载曲线被"削平"后脱靶量如何恶化。
4. **对比纯跟踪**：在默认场景下，比例导引脱靶量通常比纯跟踪小一个量级。
