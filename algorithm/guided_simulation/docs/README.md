## 快速开始

1. 在 `guidance_sim` 目录下运行 `python main.py` 启动程序。
2. 保持默认参数，点 **「▶ 开始」**（或按空格键），观察两枚导弹的弹道。
3. 看下方曲线：上图是相对距离 R(t)，下图是过载 a(t)；看右侧数据表的实时数值。
4. 结束后状态栏会给出 **命中 / 脱靶量**，画面上方显示结果横幅。
5. 拖动画布上的 **导弹(橙) / 目标(青)** 图标，改右侧参数，仿真会自动重置，方便反复试验。
6. 勾选面板 **「启用分段制导」**，再按开始：可看到**中段(暗色虚线, 未截获)→截获点 × →末段(实线寻的)**
   的完整交接过程，详见 [05 · 中段制导与拦截点计算](05_中段制导与拦截点计算.md)。

| :--- | :--- |

## 命令行用法

```bash
python main.py                          # 图形界面
python main.py --snapshot out.png       # 推进 8 s 后截图保存并退出
python main.py --mode pn                # 只跑比例导引
python selftest.py                      # 数值自检(12 个场景, 含 3 组分段制导)
python gui_test.py                      # GUI 集成测试
```

## 数学符号约定

全系列文档统一使用下列符号（二维平面、角度以 +x 轴起逆时针为正）：

| 符号 | 含义 | 单位 |
| :--- | :--- | :--- |
| R | 导弹与目标的相对距离 | m |
| λ | 视线角 (line-of-sight angle)，即从导弹指向目标的方向角 | rad / ° |
| λ̇ | 视线转率 (LOS rate) | rad/s / °/s |
| Vc | 接近速度，Vc = −dR/dt，为正表示正在接近 | m/s |
| Vm | 导弹速度(本程序中为常值) | m/s |
| Vt | 目标速度 | m/s |
| ψ | 导弹航向角 (velocity heading) | rad / ° |
| a | 导弹法向过载指令 / 实际过载 (垂直于速度方向的加速度) | m/s² |
| n | 过载倍数，n = a / g | g |
| N | 比例导引导航比 (navigation ratio) | 无量纲 |
| K | 纯跟踪航向收敛增益 | 1/s |
| τ | 执行机构一阶时间常数 | s |
| R_acq | 导引头截获距离(超过它截获不了) | m |
| FOV | 导引头视场**全角**(判据按 ±FOV/2 相对弹轴) | ° |
| t_acq | 导引头截获时刻(中段→末段的交接点) | s |
| PIP | 预测拦截点 (Predicted Intercept Point) | — |
| TOF | 飞行时间 / 拦截剩余时间 (Time of Flight) | s |
| ZEM | 零 effort 脱靶量(不再修正时的预计偏差) | m |
| g | 重力加速度 9.80665 | m/s² |
