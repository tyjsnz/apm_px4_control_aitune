# 02 · 纯跟踪法 (Pure Pursuit, PP)

> **一句话概括**：让导弹速度矢量**始终指着目标** —— `ψ = λ`，追不上就继续拐，像猎狗咬兔子。
> 实现上用增益形式：`a_cmd = Vm · K · wrap(λ − ψ)`，即航向以速率 K 指数收敛到视线方向。

纯跟踪(又称追踪法、Curves of Pursuit)是最直观的导引律，本程序中由品红色导弹体现。

---

## 1. 几何直觉

```
            目标 T ──────→ Vt
               ↑
               │  λ(视线)          ψ(航向)
               │   ↗  ······  导弹始终"看着"目标
               ●
             导弹 M ────→ Vm  (速度方向 ≡ 视线方向)
```

导弹每时每刻都把机头(速度矢量)对准目标当前位置：
- 目标在前面 → 直直追过去；
- 目标往旁边跑 → 导弹跟着转弯，弹道是一条**弯曲的追踪曲线**；
- 越靠近，转弯越"急"，因为视线在末端转得越来越快。

## 2. 数学形式

### 2.1 理想形式

```
ψ_cmd = λ            (速度矢量方向 = 视线方向, 即前置角恒为 0)
```

这是一种**位置反馈**控制：误差 `e = λ − ψ`，希望 e → 0。

### 2.2 本程序实现：增益形式

理想形式需要"瞬间"把航向转过去(无穷大过载)，工程上用一阶收敛代替：

```
ψ̇ = K · wrap(λ − ψ)
a_cmd = Vm · ψ̇ = Vm · K · wrap(λ − ψ)
```

- `wrap(·)` 把角度差归一化到 (−π, π]，避免 ±360° 跳变导致反向猛打舵。
- **K (跟踪增益, 1/s)**：航向误差的收敛速率。K 越大越接近理想纯跟踪；
  误差按 `e(t) = e0·exp(−K·t)` 衰减，时间常数为 `1/K`。
  默认 K = 4 → 时间常数 0.25 s，即约 0.25 s 内消除 63% 的离轴角。
- K 很大时行为逼近"ψ = λ"的理想追踪，但过载指令也会变大，更容易顶到 ±Gmax。

代码位置 `guidance.py`：

```python
# 纯跟踪
return self.speed * p.pp_gain * wrap_pi(los - self.heading)
```

### 2.3 与比例导引的本质区别

| | 比例导引 PN | 纯跟踪 PP |
| :--- | :--- | :--- |
| 反馈量 | **视线转率** λ̇ (速率) | **视线角与航向之差** λ−ψ (位置/角度) |
| 控制目标 | 让 λ̇ → 0(平行接近) | 让 ψ → λ(始终对准) |
| 前置角 | 有，趋于理想碰撞前置角 | 恒为 0(始终指向目标) |
| 弹道形状 | 早转弯、后段平直 | 全程持续弯曲 |
| 末端过载 | 小 | **大(可能发散)** |
| 对初始离轴 | 不敏感 | 敏感 |
| 所需测量 | λ̇、Vc | λ(一个角度即可) |

## 3. 追踪曲线与末端发散

### 3.1 追踪曲线 (Curve of Pursuit)

当目标匀速直线且导弹从后方某点出发时，纯跟踪的弹道是一族经典的**追踪曲线**：
起点切线指向初始目标位置，随后不断向目标"卷曲"。与比例导引相比，它**不提前转弯**，
总是等目标跑到侧面了才追，因此弹道弯曲度大、路径更长。

### 3.2 末端为什么会"甩尾"

纯跟踪在**离轴角不为 0** 时，末端所需的航向转率会发散。对直线运动目标做简单推导：

设横向偏差(脱靶量级)为 `y_e`，相对距离为 R，则末端需要的航向修正约为 `ψ̇ ≈ V_rel·y_e/R²`，
当 R → 0 时 `ψ̇ → ∞`。也就是说：

> 只要末端没有精确对准(存在零脱靶以外的横向偏差)，纯跟踪在最后一刻就需要**无穷大过载**去追。

实际系统受 ±Gmax 限制，导弹"来不及拐"，于是**从目标旁边划过去**，脱靶量明显大于比例导引。
这就是为什么本程序默认场景下：**比例导引脱靶量 ≈ 0.2 m 量级，纯跟踪 ≈ 60~70 m**。

### 3.3 什么时候纯跟踪反而更好

- **大离轴角发射 / 近距格斗**：目标就在前方或侧方，纯跟踪"看见就扑"，初始段路径最短。
- **末端制导的最后阶段**：某些导弹在 R 很小时切到追踪法，简化测量。
- **过载极其充裕**：近距离、高过载(30 g+)时末端发散区间很短，脱靶可接受。
- **对称尾追且正好对准**：离轴角≈0 时，两种导引律几乎重合。

## 4. 参数 K 怎么选

| K (1/s) | 行为 | 结果 |
| :---: | :--- | :--- |
| 0.5 ~ 1 | 航向"软"，跟不上视线变化 | 弹道迟钝，脱靶大，末端来不及修正 |
| 2 ~ 3 | 平衡，过载峰值较小 | 脱靶中等 |
| **4** | **默认** | **接近理想追踪，过载峰值较大** |
| 6 ~ 8 | 很接近理想 ψ = λ | 初段过载尖峰大，容易顶满 Gmax 而抖动 |
| 12 | 几乎"瞬时对准" | 指令打满，产生 bang-bang 式抖动 |

**规律**：K 增大 → 前段更"紧跟"，但过载峰值升高；K 减小 → 平滑但滞后。
因为末端发散是**几何**造成的，调 K 只能缓解、无法根治 —— 根治要靠换比例导引。

## 5. 优缺点

**优点**

- 原理极其直观，只需要测量**视线角 λ**(导引头直接给出)，不需要测 λ̇、Vc。
- 大离轴角、近距离时反应直接，弹道前段短。
- 对目标机动的响应是"看到就追"，不依赖目标速度估计。

**缺点**

- **末端过载发散**：只要离轴角不为 0，最后一段需要的转弯率急剧上升 → 脱靶量大。
- 弹道持续弯曲，**路径长、能量(速度)损失大**，远程拦截吃亏。
- 对同一点目标的"提前量"估计为 0，本质是**追赶当前位置**而非**奔向相遇点**
  （怎么算"相遇点"，见 [05 · 中段制导与拦截点计算](05_中段制导与拦截点计算.md) §3）。

## 6. 在程序里观察什么

- **弹道**：品红弹道明显比橙色更弯，末端出现"甩尾"弧线。
- **a(t) 曲线**：前段中等、**末端急剧上冲并长时间贴住 ±Gmax 虚线** —— 这就是发散的直接证据。
- **数据表 λ̇ 一行**：纯跟踪的 λ̇ 长时间不为 0(始终在追)，末端还会变大。
- **数据表 前置角**：纯跟踪恒接近 0°，比例导引则稳定在一个非零的碰撞前置角。
- **最小距离一行**：两列对比，可以直观看到 PP 的脱靶量大一个量级。

## 7. 动手实验

1. **K 扫描**：K = 1 / 4 / 12 各跑一次，观察 a(t) 末端上冲的时刻与峰值。
2. **迎头 vs 尾追**：把目标航向改成 20°(迎头)，看纯跟踪的末端发散是否更严重。
3. **纯跟踪专属场景**：把导弹初始位置拖到目标正后方且航向对准，此时 PP 与 PN 几乎重合 —— 验证"对准时二者等价"。
4. **加大离轴角**：把导弹 Y 坐标改到与目标相差很大，观察 PP 需要更久才能把机头转过来。
