# 09 末段导引策略·现代与智能方法

> **本章回答**：经典 PN 之外还有哪些路子？**微分对策、滑模、轨迹整形、协同制导、强化学习/深度学习**
> 分别怎么做、为什么有效、代价与风险是什么——以及**到底什么时候该用哪一种**。

> 前置阅读：[08 末段导引策略·经典方法](08_末段导引策略_经典方法.md)（PN/APN/OGL 的主线与执行机构约束）。

---

## 1. 一张表先定位（用什么“思想”解决问题）

| 方法 | 核心思想 | 相对 PN 多解决的问题 | 主要代价 |
|------|---------|---------------------|---------|
| 落角约束/偏置 PN | 在 PN 上叠加**方向偏好** | 从“打中”到“**从哪边打**” | 占用过载预算 |
| 微分对策导引 | 双方都是**最优对抗者**（追逃博弈） | 目标也在“最优躲”，给出**对抗性最优** | 需要对方性能界、解复杂 |
| 滑模/鲁棒 H∞ | 把误差压到**滑模面**并对不确定性**鲁棒** | 模型不确定、参数摄动下仍稳 | 抖振、需设计切换/边界层 |
| 轨迹整形 | 在 PN 上叠**时间函数**整形误差演化 | 过载分布更平滑、末端留余量 | 需 `t_go` 与整形函数设计 |
| 协同/时间控制 | 把**时间/相位**当被控量 | 多弹同时到达、饱和攻击 | 依赖通信+TOF 估计 |
| 自适应/反步 | 在线辨识不确定参数 | 未知气动/质量特性 | 计算量、收敛性证明 |
| 强化学习/深度学习 | 从数据/仿真中**学策略**或**学补偿** | 难以解析建模的场景与干扰 | 可解释性、泛化与安全性 |

## 2. 落角约束：从“命中”到“如何命中”

### 2.1 怎么做

1. **偏置 PN（Biased PN）**：`a = N·Vc·λ̇ + b(t)`，偏置项 `b(t)` 通常随 `t_go` 衰减（末段不再干扰命中）；
   设计思路是“先用偏置把视线顶到期望方向，再让 PN 收口”；
2. **终端角约束 OGL**：把终端角误差写进代价函数 → 解出**时变导航比 + 时变偏置**的闭式指令；
3. **两阶段法**：中段先机动占位、末段回落 PN（把过载预算分段使用）。[R01][R11][R12]

### 2.2 为什么 / 结果

- **为什么**：破甲/侵彻需要最佳着角，攻顶需要大落角避开正面装甲；制导目标从“点”扩展到“点+方向”。
- **结果**：通常可在**脱靶量几乎不变**的前提下把落角控制在数度内；代价是过载峰值上升、
  且对 `t_go` 估计误差敏感（`t_go` 错 → 落角错），所以常与时间估计/测距联合设计。[R11]

## 3. 微分对策（Differential Game Guidance）

- **怎么做**：把追逃写成**博弈**——拦截方最小化脱靶量/过载，目标方最大化之（同时受各自过载约束），
  求鞍点解 → 得到形如 `a_m = f(R, V_r, λ̇, 界约束)` 的对策导引律；关键参数是**机动优势比**（谁的过载更强）。[R24]
- **为什么**：当目标**也在做最优规避**时，PN 的“假设目标不最优”会高估自身能力；
  对策解把“对方也在算计我”写进闭环 → 给出**最坏情况下的最优**。
- **结果**：
  - 机动优势比 > 1（我更强）→ 存在“确保捕获区”，对策律在该区内保证收敛；
  - 优势比 ≤ 1（他更强）→ 任何制导律都无法保证命中，**结论本身有价值**（指导武器需不需要提速/提过载）；
  - 代价：解依赖**对方过载界**与线性化假设，实际实现常与 PN 形式很像（差异体现在有效导航比与偏置项）。[R01][R05]

---

## 4. 滑模与鲁棒控制（Sliding Mode / H∞）

- **怎么做**：设计切换面 `s = λ̇ + c·(λ − λ_des)`，用不连续（或边界层连续化）控制律迫使 `s → 0` 并保持；
  一旦在滑模面上，系统对**匹配不确定性**（质量/气动/目标机动的一定范围）**不变**。[R25]
- **为什么**：真实弹体参数（质量、气动系数）与目标机动都是不确定的，经典 PN 的增益是折中值；
  滑模用“高频切换”换取**对不确定性的免疫**，把问题变成“选滑模面”。
- **结果**：
  - 对模型不确定性鲁棒、可给出**有限时间收敛**证明；
  - 代价是**抖振**（chattering）→ 工程上用边界层/高阶滑模/自适应增益缓解；
  - 与执行机构带宽耦合：切换频率必须在舵机能跟的范围内（否则抖振变成实际的过载振荡）。[R05][R12]

---

## 5. 轨迹整形与能量管理（Trajectory Shaping）

- **怎么做**：把误差通道乘以一个时间函数 `W(t_go)`（如分式、指数、多项式），
  使“误差→过载”的映射**前端小、末端按需**；或直接规定 `t_go` 的误差衰减剖面。
- **为什么**：PN 的 `N` 是**常数**，只能整体折中；整形相当于**时变的 `N`**——
  这与 OGL 的时变导航比是同一思想的两种实现路径（一个从最优控制来，一个从形状设计来）。
- **结果**：过载峰值更早被利用、末端过载余量更大；对滞后系统尤其有效（提前发力补偿相位）。
  代价：依赖 `t_go` 精度，目标机动估计差时整形会“整错地方”。[R01][R26]

## 6. 协同制导（Salvo / 时间可控）

- **怎么做**：
  1. 给每弹分配**到达时刻** `t_d`，把时间误差 `t_go − t_d` 作为反馈项叠进制导律（时间受控导引）；
  2. 需要 **TOF 可控性**：通过调整**飞行路径长度**（侧向机动占位）或**速度**（推力/阻力舵）来提前/推迟到达；
  3. 多弹间经**数据链**交换到达时间/相位（[02](02_发射前准备与地面引导.md)）。[R11][R12]
- **为什么**：同时到达使防御方**火力通道饱和**（分批到达会被逐个拦截）——协同的价值是战术的，不是几何的。
- **结果**：到达时间精度取决于 TOF 估计与机动带宽；通常**路径调整比速度调整更现实**（导弹速度不可任意控制）。
  代价：需要可靠通信（时延/丢包直接影响同步精度）。

## 7. 目标机动估计：所有“先进”方法的地基

无论 APN、对策还是落角 OGL，都要知道 `a_T`（目标加速度）或至少其方向/量级：

| 估计器 | 做法 | 特点 |
|--------|------|------|
| α-β / CV 滤波 | 常速模型 | 最简单，滞后大 |
| **CT（匀转弯）滤波** | 状态含转弯率 `ω` | 对盘旋目标好（飞机最常见） |
| **IMM（交互多模型）** | CV/CT/CA 并行 + 概率加权切换 | 机动模式切换时**响应最快**、最常用 [R15] |
| 滑模观测器/扩张状态观测器 | 把目标机动当“总扰动”估计 | 不需要显式模型，但有相位滞后 |

**关键提醒**：估计器的**滞后**会直接进入制导指令（前馈项用的是“过去的机动”），
所以“更强的导引律 + 更弱的估计器”常常**不如**“普通导引律 + 好估计器”。这是升级制导律前的必做体检。

## 8. 智能方法（强化学习 / 深度学习）：怎么做、为什么、结果

### 8.1 三种典型用法

1. **学策略（端到端）**：状态（相对位置速度、`λ̇`、过载、时间）→ 神经网络 → `a_cmd`；
   用 RL（PPO/SAC 等）在仿真里训练，奖励 = 负脱靶量 − 过载惩罚 − 落角惩罚。
   *为什么可能有效*：某些“难解析建模”的约束（复杂终端条件、复合干扰）下，学出的策略能逼近甚至超过手工律。
2. **学补偿/学参数**：仍用 PN/OGL 框架，用网络在线估计**目标机动、气动偏差、滞后**，把输出当作 APN/自适应项的输入。
   *为什么更受欢迎*：**可解释、可验证**，网络只做“补丁”，框架仍是经过证明的经典律。
3. **学感知**：成像导引头的检测/识别/抗诱饵（见 [07](07_导引头与目标探测.md) §5）——
   这是目前**落地最多**的环节（纯感知问题、离线可评测）。

### 8.2 为什么不能一“学”了之（风险，务必看）

- **泛化**：训练场景分布外（没练过的机动/干扰/气象）表现可能断崖式下降——制导是**高后果**场景，尾部风险不可接受；
- **可解释性与验证**：经典律有解析收敛性证明与工程验证路径（打靶统计），RL 策略难给**最坏情况界**；
- **对抗脆弱性**：学习组件可被输入扰动（物理可实现的干扰样式）系统性欺骗；
- **算力与实时性**：机载推理需满足回路频率与确定性时延。

### 8.3 结果怎么样（诚实结论）

- 在**受限、可大量仿真**的问题上（如特定场景的落角/时间约束、机动对策），RL/DL 策略常能取得与最优控制相当的平均性能；
- 但在**开放环境、强对抗、要求最坏情况保证**的场合，工程主流仍是：
  **经典/OGL 框架 + 先进估计器 + 有限的在线学习补偿**；
- 文献更新极快且质量参差 → 🔍 建议以 AIAA JGCD、IEEE TAES/TNNLS 近年综述为入口自行检索（[R27]）。

## 9. 决策树：什么时候用哪种？

```
目标机动强、估计滞后明显? ──是──► APN / IMM+APN（先升级估计器!）
                │否
落角/时间有硬约束? ──是──► 偏置PN 或 落角OGL（[R11][R12]）
                │否
过载受限/舵机滞后大? ──是──► OGL / 轨迹整形（时变导航比，提前发力）
                │否
对手可能最优规避 + 优势比已知? ──是──► 微分对策导引
                │否
模型不确定/参数摄动大? ──是──► 滑模 / H∞（注意抖振与带宽）
                │否
多弹协同/饱和攻击? ──是──► 时间受控导引 + 数据链同步
                │否
  ★ 默认：PN（N=3~5）+ 好的目标状态估计 —— 80% 场景的性价比之选
```

**经验法则**：先修**测量与估计**（[05](05_组合导航与状态滤波.md)），再修**制导律**；
最后才考虑学习类方法，且优先做“学补偿”而非“学策略”。

## 10. 动手实验

1. 在 `guidance_sim` 里把 `N` 换成 `N_eff(t_go)` 风格（如 `N0 · (1 + k/t_go)`）对比过载峰值与脱靶，
   体会“时变导航比 = 轨迹整形/OGL”的思想；
2. 给目标加上正弦机动（需改代码），比较“直接用测得 `λ̇` 的 PN”与“带目标机动前馈的 APN 思路”的稳态滞后；
3. 实现一个**偏置项** `b(t) = b0·(t_go/T)²`，观察落角变化与过载代价的交换关系；
4. （进阶）用简单的表格/线性网络拟合“剩余偏差→过载”的映射并回放，理解“学补偿”的最小形态。
