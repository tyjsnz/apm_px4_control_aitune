## 1. 卡尔曼滤波：怎么做

### 1.1 问题设定

系统有**预测模型**（我“以为”自己该怎么动）和**量测**（传感器“说”我动成了什么样），两者都带噪声：

```
状态预测:   x_k = f(x_{k-1}) + w,     w ~ N(0, Q)   （过程噪声：模型误差、未建模机动）
量测方程:   z_k = h(x_k) + v,         v ~ N(0, R)   （量测噪声：传感器规格）
```

### 1.2 五步（怎么做，线性情形）

```
① 预测     x̂⁻ = f(x̂)                     (惯导递推)
② 预测协方差 P⁻ = F P Fᵀ + Q               (误差随时间长大)
③ 增益     K = P⁻ Hᵀ (H P⁻ Hᵀ + R)⁻¹       (预测不确定 vs 量测不确定 的权衡)
④ 更新     x̂ = x̂⁻ + K (z − h(x̂⁻))          (量测残差按 K 打折回灌)
⑤ 协方差   P = (I − K H) P⁻                  (修正后不确定度下降)
```

**直觉**：`K` 就是“信预测还是信量测”的**方差比**——`R` 大（量测噪声大）→ 信预测；`P⁻` 大（预测飘了）→ 信量测。

### 1.3 为什么是最优（为什么）

- 在**线性 + 高斯**假设下，卡尔曼滤波是**最小方差无偏估计**（后验均值=后验众数）——任何线性估计器的误差方差都不会更小；
- 递归形式使它**只存上一时刻的 `x̂、P`**，无需历史数据 → 适合机载实时计算；
- 从随机过程角度它是维纳滤波的递推实现（推导源头见 [R14]，工程细节见 [R15][R17]）。

### 1.4 非线性怎么办：EKF / UKF / 粒子滤波

| 方法 | 做法 | 适用 | 代价 |
|------|------|------|------|
| **EKF** | 在当前估计点做一阶泰勒展开（`F、H` 用雅可比） | 弱非线性（大多数导航问题） | 需推导雅可比；线性化误差大时可能发散 |
| **UKF** | 用一组 σ 点经非线性函数“采样传播”，再统计出均值/协方差 | 强非线性、无需雅可比 | 计算量略高（2n+1 个点），实现简单鲁棒 |
| 粒子滤波 | 大量加权样本逼近任意分布 | 强非线性+非高斯（多峰） | 算力大，机载需裁剪 |

**组合导航常用“误差状态（间接法）”滤波**：状态不是位置本身，而是**误差量**
（Δ位置、Δ速度、Δ姿态、陀螺/加计零偏，经典 15 维），好处是：
① 线性化更好（误差是小量）；② 惯导用高频原系统递推，滤波器只在量测到达时低频运行 → 省算力。[R07][R08]

### 1.5 紧耦合 vs 松耦合（GNSS/INS 组合）

- **松耦合**：GNSS 自己先解出位置速度，再把解算结果当量测喂给滤波器（简单、易实现）；
- **紧耦合**：直接把**伪距/多普勒原始量测**放进统一滤波器（卫星数不足 4 颗时仍能辅助，遮挡/弱信号下更稳）；
- **深耦合**：进一步把辅助信息反馈到接收机的信号跟踪环路（跟踪带宽自适应）。
  层层加深的动机都是同一件事：**在恶劣信号下尽量保住可用信息**。[R08]

## 2. 目标状态估计（另一条并行的滤波）

中段解算拦截点需要**目标的位置与速度**，它来自另一套滤波：

| 运动模型 | 状态 | 适用 |
|---------|------|------|
| CV（常速） | `x,y,vx,vy` | 目标基本不机动（巡航、直线段） |
| CT（匀转弯） | `x,y,vx,vy,ω` | 飞机持续转弯（最常用扩展） |
| CA（常加速） | + `ax,ay` | 短时高机动段 |
| IMM（交互多模型） | CV/CT/CA 并行+概率切换 | 机动模式频繁切换（高性能目标） |

**为什么不能只用最后一次测量**：单点差分测速噪声极大（位置噪声差分后放大 `√2/Δt`），
而拦截点对**速度误差极其敏感**（速度错了，外推的相遇点错得更远）——所以必须滤波。
**结果**：CV/CT 滤波把速度估计噪声压低一个数量级量级地降低拦截点 σ（具体倍数取决于量测噪声与更新率）。

## 3. Q/R 怎么调（工程核心技能）

| 现象 | 大概率原因 | 处理 |
|------|-----------|------|
| 估计**滞后**于真实变化（跟不上机动） | `Q` 太小（太信模型）/ `R` 太大 | 增大 `Q`（过程噪声），或换机动模型（IMM） |
| 估计**抖**、跟随噪声 | `R` 太小（太信量测）/ `Q` 太大 | 增大 `R`（如实标定传感器），减小 `Q` |
| `P` 收敛到 0 后又**发散**（“过于自信”） | 模型误差没进 `Q`（自洽性破坏） | 按实际未建模量标定 `Q`；加野值剔除 |
| 量测异常时**野值拉飞** | 未做残差检验 | 卡方门限 `S = H P Hᵀ + R` 检验，超限丢弃该量测 |

**标定的正道**：`R` 来自**传感器静态/动态测试数据**（不是猜的），`Q` 来自**模型失配的实测统计**；
`R` 可以查手册，`Q` 基本靠试飞数据回填——这也是滤波工程“三分推导、七分调参”的原因。[R15][R17]

**自洽性检查**（必做的 sanity check）：滤波器跑长时段时，`归一化残差 NIS = νᵀ S⁻¹ ν` 的均值应接近其自由度；
显著偏大 → `Q/R` 标小了；显著偏小 → 标大了。这是判断“到底谁调错了”的客观标尺。

## 4. 结果怎么样（典型结论）

1. **融合后误差有界**：纯 INS 误差随时间增长；INS+GNSS 后位置误差收敛到“量测噪声级”小量并保持；
   滤波还能**估计出陀螺/加计零偏**，相当于在线体检+校准。[R08]
2. **目标估计速度**：滤波后的目标速度误差比原始差分小得多 → 拦截点误差 σ 显著下降 → 截获角预算更宽（[06](06_中段制导与拦截点计算.md)）。
3. **代价与风险**：滤波依赖模型与噪声统计假设；假设错 → “自信地错”（协方差小但误差大），比不用滤波更危险。
   所以工程上必配**一致性检验**与**故障检测**（量测超限、残差发散、传感器健康位）。

1. 在 `Target.position_at()` 或 `predict_intercept()` 的输入上叠加高斯噪声（σ 分别取 10 m / 50 m / 200 m），

## 7. 本章 FAQ

**Q1：既然卡尔曼最优，为什么还用 α-β 滤波？**
因为 α-β 是常增益的稳态退化形式——零算力、无发散风险、对弱动态场景足够；
“最优”建立在模型与噪声都对的前提上，前提不成立时简单方案反而更稳。

**Q2：滤波会不会“抹掉”真实机动？**
会——这就是第 3 节“滞后”现象的来源。对策不是猛调 `Q`，而是**换模型**（CT/IMM）让模型自己跟上机动。

**Q3：为什么导航滤波和目标跟踪滤波不能合并成一个？**
可以合（联合状态向量），但维度翻倍、量测异构、更新率不同，工程上通常**分层**：
自身状态（高频、多源）、目标状态（低频、单源）分别滤波，在“拦截点解算”处汇合（见图 fig04）。
